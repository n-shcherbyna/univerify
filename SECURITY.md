# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in UniVerify, please report it responsibly.

**Do not open a public GitHub issue.**

Instead, please email: **nazar.shcherbyna@gmail.com**

Include:

- A description of the vulnerability
- Steps to reproduce or a proof of concept
- The affected component (smart contract, SDK, web app, API)
- Any potential impact assessment

## Response Timeline

- **Acknowledgment**: within 48 hours
- **Initial assessment**: within 1 week
- **Fix or mitigation**: timeline depends on severity

## Scope

The following are in scope:

- Smart contracts in `contracts/src/`
- API endpoints in `apps/web/app/api/`
- SDK and core library logic
- Authentication and authorization mechanisms

## Out of Scope

- Vulnerabilities in third-party dependencies (report these upstream)
- Issues in development/test configurations
- Social engineering attacks

## Disclosure

We follow coordinated disclosure. Please allow reasonable time for a fix before any public disclosure.

## Acknowledgments

We appreciate security researchers who help keep UniVerify safe. Contributors who report valid vulnerabilities will be acknowledged in the project (unless they prefer to remain anonymous).
